# Battery Swap Optimization Prototype (Simulated)

## What is this?
This is a **learning prototype** inspired by Sun Mobility.  
It predicts **battery swap demand**, shows **station congestion**, and optimizes **charging vs swapping** based on **tariff, solar, and battery health**.  

> ⚠️ Uses **simulated data only** for learning purposes.

---

## Features
- Predict demand and wait times
- ROI Calculator (time & money saved)
- Map visualization of Bengaluru stations
- Energy optimization (charging vs swap)
- Interactive web app with Streamlit
